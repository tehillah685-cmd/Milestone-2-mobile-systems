**BioPulse Wireframes**


This folder contains the BioPulse mobile application wireframes, 
illustrating the key screens and interactions in the user journey. The designs focus on onboarding, NFC pairing, real-time monitoring, 
threat detection, emergency response, and alert resolution.


Profile/Settings and Notifications/Alert History screens are not included in the current prototype, 
as the project prioritises the core safety workflow. These features may be considered for future development.



The wireframes support the UI/UX design process and provide a visual reference for the BioPulse prototype.
