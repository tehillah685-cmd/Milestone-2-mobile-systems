BioPulse User Stories

This folder contains the User Stories developed for the BioPulse Monitoring System.

User stories were derived from the user personas identified during the requirements analysis phase and were used to translate user needs into functional system requirements. These stories provided a user-centred foundation for the design and development of the BioPulse prototype.

The user stories helped guide:

Screen design
Navigation structure
Emergency workflows
Monitoring functionality
Accessibility considerations
User journey development
