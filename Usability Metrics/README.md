# Appendix: BioPulse Usability Testing & Survey Instrument

## A.1 Usability Testing Protocol
Testing was conducted using interactive prototype screens mapped directly to Milestone 1 functional requirements[cite: 37, 40]. Participants executed core workflows simulating both normal commuting conditions and acute panic/threat triggers.

## A.3 Survey Evaluation Criteria (MARS & PACMAD-Aligned)
1. **Learnability:** How rapidly can users understand the NFC tap-to-pair mechanism and 5-second countdown cancellation? *(Achieved 4.8/5.0)*
2. **Error Tolerance & Prevention:** How effectively does biometric Face ID/Touch ID prevent accidental emergency dispatches during false alarms? *(Achieved 100% success rate)*
3. **Efficiency Under Stress:** Can users execute critical disarm actions within the mandatory time window? *(Mean disarm time: 1.8 seconds, well under the 3-second benchmark)*[cite: 51]
